# AI-Powered Library

A modern, full-stack library application built with React, Vite, Firebase, and the Google Gemini API. This application allows users to browse a catalog of books, borrow titles, manage their active and past borrows in a personal dashboard, and "read" the books—with content dynamically generated by AI.

## Features

- **Book Catalog:** Browse available books with details like title, author, and inventory status.
- **User Authentication:** Secure login using Firebase Authentication.
- **Borrowing System:** Users can borrow books (with enforced limits) and return them. It uses Firestore transactions for real-time inventory tracking.
- **Reading Experience:** Once borrowed, users can dive into the first chapter of the book. The story content is dynamically generated by the Gemini model based on the book's title and author!
- **AI Librarian:** Chat with a smart AI librarian that understands the library's catalog and provides personalized book recommendations.
- **Admin Dashboard:** Secure admin area (protected by a secret key and Firebase role-based access control) to add and manage books in the collection.
- **User Dashboard:** A personal space to view currently borrowed books, read them, and track a history of returned books.

## Tech Stack

- **Frontend:** React (TypeScript), Vite, Tailwind CSS, shadcn/ui, `lucide-react`.
- **Backend & Database:** Firebase (Authentication, Firestore Database) with secure rule validations.
- **AI Integration:** Google Gemini API (`@google/genai` SDK) for dynamic book content generation and chatbot librarian features.

## Getting Started

### Prerequisites

- Node.js
- Firebase Project (with Firestore and Authentication enabled)
- Google Gemini API Key

### Configuration

Create a `.env` file from the example and configure your environment variables:

```bash
cp .env.example .env
```

Ensure the following variables are set:
- `GEMINI_API_KEY`: Your Google Gemini API Key (keep this private).
- `VITE_ADMIN_SECRET_KEY`: A secret key needed in the UI to access the Admin page.

### Installation

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

### Deployment

The app can be built for production using:

```bash
npm run build
```
